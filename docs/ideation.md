# Project Ideation
- **Topic:** Undergraduate Calculus (Focus: Differentiation)
- **Target Audience:** NTU EEE Students
- **Core Game Mechanics:** XP, Levels, Streaks, Hearts (lives), Badges, Adaptive Difficulty.
- **AI Integration:** LLMs used strictly for contextual hints and step-by-step feedback, not as a free-form chatbot.
- **Platform:** Web application (Targeting GEAP deployment).
