# Skill Tree (Level Progression)

The prototype's learning path covers differentiation through six sequential nodes. Players must clear each node to unlock the next. Mini-tests gate progression between nodes.

## L0 — Tutorial: What is a Derivative? (Learning Objective 1)
- Guided, no scoring, no hearts.
- Introduces the derivative as rate of change with a simple visual slope explorer.
- Completion unlocks L1.

## L1 — First Steps: Power Rule (Learning Objective 2)
- 8 questions + mini-test (3 questions).
- Question types: MCQ, numerical.
- Completion unlocks L2.

## L2 — Side by Side: Product Rule (Learning Objective 3)
- 8 questions + mini-test (3 questions).
- Question types: MCQ, numerical, symbolic.
- Completion unlocks L3.

## L3 — Fair Share: Quotient Rule (Learning Objective 3)
- 8 questions + mini-test (3 questions).
- Question types: MCQ, numerical, symbolic.
- Completion unlocks L4.

## L4 — Inside Out: Chain Rule (Learning Objective 4)
- 8 questions + mini-test (3 questions).
- Question types: MCQ, numerical, symbolic.
- Completion unlocks L5.

## L5 — Boss: Rule Mixer (Learning Objective 5)
- 10 mixed questions + final test (5 questions).
- All question types, including matching (function ↔ derivative).
- Hints and error-feedback active here (Learning Objective 6).

## Progression Rules
- A node unlocks only after the previous node's mini-test is passed.
- A wrong answer costs one heart; losing all hearts restarts the current node only, not the whole tree.
- Using a hint caps that question's XP at 50%.
- Stars (1–3) awarded per node based on accuracy and hint usage.
