# UI Wireframes

Hand-drawn low-fidelity wireframes for the core game loop (12 Sep 2026).

1. wireframe_1_main_menu — main menu (PLAY, streak, XP)
2. wireframe_2_level_map — level map L0–L5 with locks and tests
3. wireframe_3_mcq — MCQ question screen (progress, hearts, options, CHECK)
4. wireframe_4_symbolic — symbolic input screen (empty answer box, math keyboard)
5. wireframe_5_hint_popup — hint / try-again pop-up (3-level hints)
6. wireframe_6_results — results screen (stars, XP, streak, CONTINUE)
